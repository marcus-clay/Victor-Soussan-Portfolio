## Session 29 mars 2026 : page Approche

### Ce qui a été créé

**Nouvelle page /approche (FR) / /approach (EN)** intégrée au site portfolio, accessible depuis la navigation principale.

Fichiers créés :

### Contenu

Source : 2 decks d'entretien Givaudan (Head of Design + Lead PM), convertis en markdown dans `docs/process/`.

Structure finale (V3, après plusieurs itérations) :
1. **Hero** : ouvre sur le problème (produits B2B qui échouent), pas sur le CV. Sans mention « 15 ans ».
2. **Process** (tabs interactifs) : Cadrer / Matérialiser / Arbitrer. Chaque onglet contient description, détail, output, exemple terrain.
3. **Ce qui guide les décisions** (accordion) : 3 principes avec exemples intégrés. Premier ouvert par défaut.
4. **Travailler ensemble** (accordion) : PM, devs, culture design. Premier ouvert par défaut.
5. **Ce que je produis par phase** (carrousel horizontal) : 6 glass cards avec illustrations SVG minimalistes, snap scroll, flèches navigation, dots mobile.
6. **CTA** : 3 projets liés (France VAE, Toolkit, Connect) + 2 articles + AuthorContactCard.

### Interactions et motion

- Barre de progression de lecture (2px, brand blue, scaleX GPU)
- Scroll-triggered reveals (opacity + translateY + blur, Jakub recipe)
- Images collapsibles (clic pour révéler, clip-path animation)
- Tabs process avec AnimatePresence mode="wait"
- Accordions avec animation hauteur + chevron rotatif
- Carrousel livrables : snap-x, flèches avec active:scale, dots paginés
- Cards projet : hover scale + shadow lift + arrow translate
- prefers-reduced-motion sur tous les éléments animés

### Décisions de design (validées par Victor)

- Pas de TOC sidebar ni dropdown (page trop courte pour en justifier une)
- Pas de bordures colorées sur les accordions (« style IA generated » rejeté)
- Pas d'illustrations SVG dans les onglets process (revert demandé par Victor)
- Illustrations SVG conservées uniquement dans le carrousel livrables
- Images dans des containers blancs avec padding uniforme (pas bg-gray-50 qui se confond avec le fond de page)
- Registre « je/on » sans tutoiement, pas de « 15 ans », orienté valeur apportée pas CV

### Règle design system ajoutée
