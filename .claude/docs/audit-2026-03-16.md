3. Ajouter updateMetaTags() dans chaque case study (0.5h, fix SEO)

5. Installer Tailwind en dépendance build, retirer CDN (1h, -30 Ko CSS)

## Détail des findings

### Performance critique
- App.tsx contient routing, states, data, rendu : extraire en modules
- Chaque case study embarque ~600-850 lignes de traductions inline
- Tailwind CDN = CSS générée au runtime dans le navigateur
- 53 icônes Lucide importées dans App.tsx, beaucoup inutilisées sur homepage

### Qualité code
- 111 erreurs TypeScript (corrigées dans ce commit)
- Pas d'error boundaries pour les pages lazy-loaded
- console.log en production (App.tsx lignes 2992, 3067, 3338, 6043)
- Code dupliqué ~25-30% entre case studies (header, TOC, gallery, CTA)

### Sécurité
- EmailJS credentials en dur (pas de secret, mais mauvaise pratique)
- Pas de Content-Security-Policy header
- Pas de SRI sur CDN resources

### SEO
- Meta tags non mis à jour pour les routes case study
- Structured data manquante pour case studies individuels
- Hreflang non défini pour pages case study
- OG image dimensions non spécifiées
