# French terms in English-language outputs

Rules for preserving correct French orthography when writing in English.

## 1. Core rule

All French proper nouns, place names, organization names, and loanwords retain their original French accents and ligatures in English text. No exceptions.

## 5. Ligatures in English context

| Wrong | Correct |
|---|---|
| oeuvre (body of work) | œuvre |
| hors d'oeuvres | hors d'œuvres |
| manoeuvre | manœuvre |

## 6. Titles and headers

French terms in English titles and headers follow the same rules. When a French word appears in an English title, it retains its accents regardless of whether the title is in all caps, title case, or sentence case.

| Wrong | Correct |
|---|---|
| ECOLE POLYTECHNIQUE OVERVIEW | ÉCOLE POLYTECHNIQUE OVERVIEW |
| Societe Generale Annual Report | Société Générale Annual Report |

## 7. Technical context

In code, variable names, and technical identifiers, ASCII equivalents are acceptable when the system does not support Unicode. In all other technical writing (documentation, comments, README files), French accents are required.

```
// Code: acceptable
const societeGenerale = ...

// Documentation: required
// Integration with Société Générale API
```

## 8. Mixed-language documents

When a document alternates between French and English sections, apply the full `francais-parfait` rules to French sections and these reduced rules to English sections. The transition between languages does not relax accent requirements.
