# 03 – Connect Dashboard - Modular Foundation (2020)
Subtitle: A vision-casting prototype designing a customizable, web-based, teacher-centric dashboard

## Context & Vision

By 2020, the need to replace the legacy Android launcher became critical. We needed a system that could address the complexity of teacher workflows (app access, session control, notifications) in a responsive, flexible way. Connect was conceptualized as a web-based, fully modular dashboard designed specifically for teachers. Its purpose was to serve as a high-fidelity internal demonstrator to test the technical feasibility of a grid-based React layout and secure C-level buy-in for a major product pivot.

## My Role

Product Design Lead: Initiated the design sprint, co-authored the PRD, and drove the full UX/UI development of the dashboard interface.

Technical Prototyping: Worked directly with a developer to build a functional prototype using React Grid Layout (RGL) and iframe containers to test modularity.

System Definition: Designed the quick action tiles, notification system, and core app card component logic.

## Design Objectives

This project was highly experimental, aiming to prove several key concepts simultaneously.

Modular Flexibility: Design a dashboard where teachers could potentially personalize and reorganize feature blocks (e.g., App Catalog, Quick Actions, Class Status).

Web-First Performance: Prove that a complex, dynamic dashboard could load quickly and reliably via a browser on existing tablet hardware.

Notification Clarity: Create a prioritized notification system that surfaced key information (e.g., student requests, new shared lessons) without becoming distracting.

Unify Entry Points: Consolidate the access points for disparate applications and classroom control tools into a single, coherent view.

## What We Made

The Connect Dashboard prototype was a comprehensive demonstrator, not just static mockups.

RGL-based Dashboard: Utilized a grid layout library in React to allow a modular structure, containing embedded apps/iframes and custom component widgets.

Quick Action Tiles: Designed a dynamic area for the teacher's most frequent tasks (e.g., "Start Session," "Share Document," "Lock Devices").

App Catalog Integration: The catalog module provided searchable, filtered access to all educational apps, linking directly to MDM policies.

Visual Identity Leap: Introduced a cleaner, more modern design language (colors, typography, spacing) that became the blueprint for the entire future SQOOL Suite.

## Outcomes

While Connect was never launched as the single product, it was arguably the most influential design artifact of the year.

Strategic Pivot Catalyst: The experiment was successful in highlighting the technical and UX complexity of a monolithic dashboard, directly leading to the strategic decision to split the vision into the specialized, focused SQOOL Apps Suite (Classe, Partage, etc.).

Technical Validation: It validated the use of React, web technologies, and a modular component approach, providing confidence to the engineering teams.

Internal Alignment: The high-fidelity demonstrator was crucial for communicating the design team's strategic vision to C-level executives and product leadership.

## Learnings

Vision Prototypes Sell: A functional, well-designed prototype can be a more powerful tool for internal persuasion and strategic influence than months of abstract documentation.

Knowing When to Pivot: Successfully identifying the point where the vision (single dashboard) must pivot into execution (suite of apps) is critical to product health.

System Foundation: The design language born in Connect was the fundamental UI/UX investment that paid dividends across all subsequent SQOOL applications.
