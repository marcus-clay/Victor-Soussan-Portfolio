### Comment on fonctionne ensemble

###### Trois principes

```
Préparation rigoureuse
Chaque atelier a un scénario, des exercices,
un livrable défini.
```
```
Transparence continue
Le PM voit l'avancement au fil de l'eau.
On ajuste en temps réel.
```
```
Décisions documentées
Chaque arbitrage est logué.
On ne refait pas les mêmes débats.
```
###### Répartition PM / Designer

```
Specs produit
Responsabilité du PM. Le designer produit les
maquettes annotées et les parcours documentés qui
les alimentent.
```
```
Priorités et arbitrages
PM et designer s'alignent sur les priorités en amont, et
les portent ensemble devant les stakeholders.
```
```
Présentation du design
Le PM a une visibilité continue sur la conception. On
présente ensemble quand c'est prêt. Prototypes avec
US associées
```
